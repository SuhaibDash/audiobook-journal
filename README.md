# Audiobook Journal

A private, local-first iPhone companion for audiobook listeners. It helps a
listener remember books, series details, and thoughts captured while listening.

## Status

Planning. See [the product brief](docs/product-brief.md) and
[v1 requirements](docs/requirements.md).

## Principles

- Make capturing a thought fast enough to use during an audiobook.
- Keep private reading data local and available offline.
- Earn complexity through real use; sync and accounts are later milestones.
